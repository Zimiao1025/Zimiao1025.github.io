# Hongliang Li — Personal Website

A custom, responsive Jekyll site for `https://zimiao1025.github.io`, designed around Hongliang Li's work in biological foundation models and AI-driven drug discovery.

## Publish on GitHub Pages

1. Create a public repository named `Zimiao1025.github.io` under the `Zimiao1025` account.
2. Copy the contents of this directory to the repository root.
3. Push to the default `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

GitHub will publish the site at `https://zimiao1025.github.io` after the first build completes.

See [BLOGGING.md](BLOGGING.md) for the blog-writing workflow.
